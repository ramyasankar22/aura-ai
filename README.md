# 🌿 Aura AI — Voice-Enabled Wellness Companion

A voice-enabled mental wellness app powered by LangChain + LLaMA 3.3 70B via Groq.

## ✨ Features
- 🎙️ Voice input via Whisper STT + gTTS response
- 🧠 RAG-powered journal — write, store, and discuss entries with AI
- 🎚️ Emotion intensity slider (1–10)
- 📊 Mood tracking graphs
- 🔐 Multi-user login with bcrypt
- 💡 Context-aware wellness tips

## 🛠️ Tech Stack
LangChain · Groq API · LLaMA 3.3 70B · Whisper · gTTS · Streamlit · SQLite · Plotly · bcrypt
